# Introduction

ModerateAI brings AI-powered support and moderation into one workspace across Website, Telegram, and Discord.

## Core Value

- Deliver faster support responses.
- Capture qualified Leads from website chat.
- Moderate conversations across multiple channels.
- Manage team access with role-based permissions.

## What You Can Do

- Connect one workspace to all supported channel types.
- Run destination-level limits based on plan entitlements.
- Track usage quotas and destination caps from the dashboard.
- Manage users, account access, and plan states as an owner/admin.
